# Restaurant Ordering System

A beginner-level Python project that simulates a simple restaurant ordering system.

## Features

- Displays a restaurant food menu with prices.
- Allows customers to select food items.
- Checks item availability.
- Calculates the total order amount.
- Displays order confirmation messages.

## Technologies Used

- Python 3
- Dictionaries
- Conditional Statements
- User Input
- Variables and Operators
- f-Strings

## How It Works

1. The program displays the restaurant menu.
2. The customer enters their desired food item.
3. The program checks whether the item is available.
4. The customer can add additional items.
5. The program calculates and displays the final bill.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the Python file.

## Project Type

Beginner Python Programming Project.
